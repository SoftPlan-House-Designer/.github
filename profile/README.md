# SoftPlan

> SoftPlan keeps a residential set on one Windows desk: open the house, check the framing view, and leave the elevation sheet with the same project.

---

## Session Card

| Slice | What you do in SoftPlan | What remains |
|-------|-------------------------|--------------|
| Arrival | Open SoftPlan and name today's residential project | A titled house |
| Focus | Keep only live rooms on the SoftPlan house designer | A short room list |
| Frame | Open SoftPlan framing views for the same walls | A wood note |
| Check | Read SoftPlan elevation sheets before a large change | A confirmed set |
| Handoff | Mark finished rooms inside SoftPlan | A note for the next visit |

## Four Beats

1. **Name the house.** Give the SoftPlan residential project a short title before you list rooms.
2. **Pin the live rooms.** Keep current spaces on the SoftPlan house designer and leave unused wings aside.
3. **Read the frame.** Open SoftPlan framing views before you change a wall that already has a wood note.
4. **Check elevations.** Read SoftPlan elevation sheets before you archive a face of the house.
5. **Close the loop.** Clear finished rooms so the next SoftPlan visit does not start with a search.

## First Questions

**Does SoftPlan replace every other program?**
No. SoftPlan sits beside the renderer, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate SoftPlan profile.

**Will SoftPlan feel heavy on an older laptop?**
No. SoftPlan is meant to stay readable during a normal house session.

**What should a new user try first?**
One small SoftPlan room list today, then the same elevation sheet tomorrow.

**Do framing views leave the house plan?**
No. SoftPlan framing views stay on the same SoftPlan residential project as the elevations.

## Who Sits Down at SoftPlan

- **House designer** — rooms stay on the SoftPlan plan.
- **Framing desk** — wood notes stay with SoftPlan framing views.
- **Elevation set** — faces of the house stay on SoftPlan elevation sheets.
- **Client work** — drafts and delivery files stay apart inside SoftPlan.
- **Shared desk** — each SoftPlan profile keeps its own pins.
- **Handoff** — the next person can read the SoftPlan note without a tour.

## Field Note

SoftPlan is easier to trust when the residential set stays smaller than the folder it came from. A named house shows what is active, the room list shows what you will touch today, and the closing note tells the next person which elevation changed.

## One Real Pass

Pick a house that already has a name. Open it in SoftPlan, keep only those rooms on the designer, and finish one framing or elevation step you can see.
